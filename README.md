# Proyecto_Final_Progra2
# Sistema de Préstamos

## Descripción
Proyecto desarrollado en equipo para crear un sistema de préstamos. El código fuente y los avances se compartirán mediante Git y GitHub.

## Requisitos
- Git
- El lenguaje de programación y las herramientas que establezca el proyecto.
- Un editor de código compatible con el lenguaje utilizado.

## Instalación del proyecto

1. Instalar los programas necesarios.
2. Clonar el repositorio en la computadora.
3. Entrar en la carpeta del proyecto.
4. Seguir las instrucciones de configuración que se añadirán cuando se defina la estructura del programa.

### Descargar el proyecto por primera vez

```bash
git clone URL_DEL_REPOSITORIO
cd NOMBRE_DE_LA_CARPETA
```

Reemplazar `URL_DEL_REPOSITORIO` por la dirección real del repositorio de GitHub.

## Cómo actualizar el proyecto

Antes de comenzar a trabajar, descargar los últimos cambios:

```bash
git pull
```

## Cómo subir los cambios

Después de modificar el código, ejecutar:

```bash
git add .
git commit -m "Descripción de los cambios"
git push
```

- `git add .`: prepara los archivos modificados.
- `git commit`: guarda un registro de los cambios.
- `git push`: sube los cambios al repositorio compartido.
